# Catalogue and photo pipeline

`watches.json` is the source of truth. Each entry is one **photographed watch**: brand, model, the visible variant, which collections it belongs to (`men`, `women` or both), and its design attributes.

An entry is shown in the app only when all of the following hold:

1. `status` is `"verified"`, and
2. it has an `image` whose file exists in `public/watches/`, and
3. the image records **where it came from, who made it and under what licence** (`image.source`), and
4. someone has **checked that the photo shows this watch** (`image.verification`).

Entries with `status: "wanted"` have no photo yet. They are never shown, never suggested and never counted in results. [`MISSING_ASSETS.md`](MISSING_ASSETS.md) lists them and is regenerated by `npm run catalogue:validate`.

## Rules for photos

- **Correct match.** The photo must show the watch named in the entry. When only the model family can be confirmed (not the exact reference), use `identity: "model-family"`. The app then shows only brand + model family. When only the brand is certain, use `"brand-only"` and the app shows "Brand (model not identified)". A generic watch photo must never be filed under a specific model.
- **Attributes describe this photo.** If the photo shows a blue face where the entry expected black, correct the attributes (`--set dialColour=blue`) rather than keeping the photo "roughly right".
- **Documented rights.** Accepted automatically: CC0, public domain, CC BY, CC BY-SA. Refused: NC, ND, GFDL-only and anything unclear. `personal-use-only` exists for private local use (your own photos, or images you may use privately). It is allowed, but the validator warns about each one, and each must be replaced before any public release.
- **One watch, clearly visible.** Prefer a front view with the whole watch in frame and a calm background. Avoid group shots, heavy watermarks, and photos where hands or clothing dominate.

## Workflow

```bash
# 1. Find candidates (Wikimedia Commons; add --openverse for Flickr CC images)
npm run catalogue:find -- --id rolex-submariner,cartier-tank
#    → catalogue/candidates/<id>/sheet.jpg (numbered contact sheet), <n>.jpg, candidates.json

# 2. Look at the sheet and the chosen photo. Is it this watch? Do the attributes match?

# 3. Accept, correcting attributes to what is visible
npm run catalogue:accept -- rolex-submariner 4 --identity model-family \
  --set dialColour=black,band=bracelet --notes "Ref 16610 visible on rehaut"

# 4. Validate (also regenerates MISSING_ASSETS.md)
npm run catalogue:validate
```

Your own photo, or one you may use privately:

```bash
npm run catalogue:add-own -- --id cartier-tank --file ~/Pictures/tank.jpg \
  --author "Your name" --license "Own photo" --source "own photo" --usage personal-use-only
```

The sources must be reachable from wherever you run `catalogue:find`: `commons.wikimedia.org` and `upload.wikimedia.org`, plus `api.openverse.org` and `live.staticflickr.com` for `--openverse`.

## Opening rounds

`opening-rounds.json` has 20 **slots** per collection. Each slot lists interchangeable watches of the same kind in order of preference. The app uses the first one that has a verified photo and skips a slot with none. Consecutive slots differ deliberately (shape, colour, strap, style), so the first 20 cards cover the whole range. The list is meant to be neutral and does not reflect anyone's favourites.

## Attributes

The vocabulary and its plain-language labels are in [`src/domain/taxonomy.ts`](../src/domain/taxonomy.ts). The validator rejects unknown values.

| Attribute | Values |
| --- | --- |
| style | dress, minimalist, everyday, sport-ring, chronograph, pilot, field, integrated, jewellery, playful, digital, smart, sculptural |
| caseShape | round, rectangular, square, cushion, octagon, oval, unusual |
| caseColour | silver, gold, rose, two-tone, black, white, colour |
| dialColour | black, white, blue, green, grey, brown, champagne, pink, warm, pearl, skeleton, screen |
| band | bracelet, leather, rubber, fabric, mesh, chain, resin |
| heft | delicate, balanced, bold |
| busyness | clean, moderate, busy |
| markers | sticks, arabic, roman, minimal, gems, digital |
| bezel | plain, numbered, fluted, gems, decorative |
| era | classic, modern |
| sparkle | none, some, lots |
| features (list) | date, moon, subdials, open, gmt |
